BUILDApple Silicon only

The release is built for arm64 Macs and delivered as a DMG.

SIGNINGAd-hoc signed

The app is ad-hoc signed without a paid Apple account, so macOS may ask you to confirm the first launch.

DATALocal service required

Start the Productivity OS data service before opening Workflows.

FIRST LAUNCH

Install in under a minute.

  1. 1

    Open the DMG and drag Workflows into Applications.

  2. 2

    Start the local data service with cargo run -p data-service.

  3. 3

    If macOS blocks launch, Control-click Workflows and choose Open.
